02 The problem

Why visual review of gameplay is hard

When a team recreates the look of a reference — a trailer, a competitor build, an art-direction target — the feedback loop usually runs through two video players, a notes document and a lot of scrubbing.

01Manual video comparison

Reviewers jump back and forth between the reference and the implementation, trying to hold one frame in memory while finding the other.

00:10
00:15

02Mismatched timestamps

The same gameplay event rarely happens at the same second in both videos, so "compare at 0:10" does not compare the same moment.

03Scattered feedback

Notes end up spread across chat threads, screenshots and documents, detached from the exact moment they describe.

"The camera feels wrong…"?

04Unclear technical feedback

Comments describe a feeling, not a fix. A developer still has to work out which Unity setting, component or value should change.

What exactly is wrong — height, distance, field of view, or timing?

05Repetitive review work

Every new build means the same steps again: load both videos, find the moments, compare, write notes — with little carried over from the previous round.

03 The solution

One workspace from comparison to feedback

FrameMind AI puts both videos, the matched moments, the extracted frames and the feedback in one place — and keeps them together for the next review.

Problem

  • Two players, constant switching
  • Events at different timestamps
  • Notes scattered across tools
  • Vague, non-technical comments
  • Same steps every iteration

FrameMind AI

  • Dual players with shared controls
  • Manually matched frame & clip pairs
  • Frames extracted at each video's own time
  • Structured AI feedback per pair Experimental
  • Sessions saved locally for later review

Expected benefits

  • More organized comparisons
  • Differences tied to exact moments
  • Clearer, categorized feedback
  • Concrete Unity starting points
  • Fewer repeated manual steps

BManual timestamp matching

Match the moments that belong together

Pause the reference on a gameplay moment, pause the current video on the same moment, and add the pair. The two times are expected to differ — adding a pair never moves or syncs the videos.

  • Use the live player time or type mm:ss.ss, with an optional event description
  • Click a pair or its numbered marker to jump each video to its own time
  • Edit, delete and clear; duplicates (within 50 ms) and out-of-range times are rejected
  • Pairs are saved with the session when the local backend is running
Matching is deliberately manual. Automatic video synchronization or scene matching is not part of FrameMind AI today.

EAI visual feedback

Structured feedback from a local Codex CLI

Analyze sends the selected pair's frames to the Codex CLI on your computer, signed in with your ChatGPT account. The answer must match a strict JSON schema, is validated, stored, and shown as feedback cards on the timeline.

  • Categories: Camera, Composition, Lighting, Colors, Animation, VFX
  • Each issue: title, severity (Critical / Major / Minor / Suggestion), confidence, observation, why it matters, how to improve, and a suggested Unity fix
  • Reference and current timestamps plus evidence frames; clicking feedback seeks both videos
  • Codex model chosen in Settings → AI Provider; Login with ChatGPT and Logout from the app
  • Up to 20 issues per pair, most severe first
Experimental. The full pipeline is implemented and covered by automated tests using a simulated Codex CLI. Runs against a real model on real gameplay are still being validated, and the quality of real AI feedback has not been evaluated yet. FUnity project (optional)

Let the AI read your Unity project

Each analysis can also read the Unity project the videos come from. The AI then points at the real file, GameObject, component and value to change, instead of a general tip.

  • 1Open New Analysis. Right above the Analyze button, open the Unity project list and choose Add a project…
  • 2Click Choose folder… and pick the project folder, the one that contains Assets and ProjectSettings. You can also paste its path and click Connect.
  • 3Click Folders, tick only what this review needs (for example Assets/Scenes or your camera and VFX folders), then click Save folders.
  • 4Click Analyze. Next time, pick the same project from the list: its folders are remembered. Choose None: videos only to analyse without it.
Read-only and limited. The AI opens only the folders you tick. The rest of the project, Library and the rest of your Mac stay blocked, and nothing is ever changed. The files it reads are sent to OpenAI with the analysis, and an analysis takes longer (up to 10 minutes per pair).
Scenes and prefabs are readable only with Edit → Project Settings → Editor → Asset Serialization → Force Text. Nothing ticked means the videos only, exactly as before.

06 Expected benefits

Designed to improve review quality

What FrameMind AI aims to change in a visual review loop.

More organized comparisons

Designed to keep both videos, matched moments and their feedback in one session instead of separate tools.

Easier to spot differences

Side-by-side frames taken at each video's own timestamp aim to make visual differences easier to see.

Clearer communication

Categories, severity and "why it matters" are designed to turn "it feels wrong" into a specific, shareable observation.

Structured Unity suggestions

Each feedback item includes a suggested Unity fix as a starting point — to be reviewed by the developer before acting on it.

Traceable reviewed moments

Pairs, frames and results are saved with timestamps, so a reviewed moment can be reopened and checked again later.

Fewer repeated steps

Saved sessions and reusable pairs can reduce the manual work of re-finding the same moments for every build.

These are intended outcomes. FrameMind AI has not been measured in a production team yet, so this page makes no claims about time saved or accuracy.

07 Technology

How FrameMind AI is built

A local-first architecture: a single HTML page, a small FastAPI server on 127.0.0.1, and the official Codex CLI — no cloud service of its own and no API keys.

Standalone page

submission/index.html
  • One HTML file, opened by double-click (file://)
  • Vanilla JavaScript, strict Content-Security-Policy, no CDN
  • Players, timelines, pairs and Canvas frame extraction work offline
  • A Next.js 16 + React version exists for development
HTTP + pairing code

Local backend

FastAPI · 127.0.0.1 only
  • Streaming upload with type, signature and size checks
  • Sessions, pairs, analysis jobs and feedback in SQLite (SQLAlchemy)
  • Analysis jobs with a bounded worker pool and status polling
  • Pydantic validation of every AI answer
subprocess

FFmpeg / FFprobe

Metadata & frame extraction

Codex CLI

codex exec · read-only sandbox

Local data folder

SQLite database, videos, frames
HTML · CSS · JavaScriptPython · FastAPISQLite · SQLAlchemyPydanticFFmpegOpenAI Codex CLIBash & PowerShell launchers

Locked-down AI runs

Codex runs with a read-only permission profile that can see only the frames of the current run and its own program files. Web search is disabled and the prompt contains no user text in arguments.

No API keys

Analysis uses ChatGPT sign-in through Codex CLI. API-key sign-in is refused by default, and tokens are redacted from logs and error messages.

Local by default

The backend listens only on 127.0.0.1 and accepts the file:// page only with a pairing code. Data stays in a folder on your computer.

08 Limitations

Current capabilities and requirements

An honest view of what works today, what needs the local backend, what is still experimental, and what is planned.

Works offline

In the HTML page alone, no backend

  • Load and play two videos with all player controls
  • Frame and clip pairs with validation, kept as a browser draft
  • Per-video timelines with markers and bands
  • Frame extraction in the browser (Canvas)
  • EN / VI / KO interface

Needs local backend

Started by the FrameMind launcher

  • Upload and storage of videos with FFprobe metadata
  • FFmpeg frame extraction at exact timestamps
  • Saved sessions, Analysis History and restore
  • Codex sign-in, model selection and AI analysis
  • Clear All Data on disk

Experimental

Implemented, not fully validated

  • AI analysis with a real model on real gameplay (tested end-to-end only with a simulated Codex)
  • Feedback written in Vietnamese / Korean by a real model
  • Windows launcher (not yet run on a real Windows PC)
  • macOS launcher on machines other than the development Mac

Planned

Not implemented yet

  • Full Video analysis (shown as "Future")
  • Markdown / JSON report export
  • Browsing every past analysis job in History
  • Cancel button and cost estimate for running analyses
  • Frame stepping at the video's real fps (currently 30 fps)

Required to run

BrowserChrome or Safari (verified); Firefox not tested
Operating systemmacOS (one-click launcher) · Windows 10/11 launcher experimental
Python3.9–3.13 for the local FastAPI backend (installed by the launcher after confirmation)
FFmpegFor metadata and frame extraction on the backend
Codex CLIFrameMind's own copy, updated to the latest release at each start
ChatGPT accountSign-in through Codex CLI; analyses count toward the plan's Codex usage limits
InternetNeeded for AI analysis and first-time installs; not for offline comparison

Known limitations

  • A single HTML file cannot run a CLI, so AI analysis always goes through the local backend.
  • AI results depend on the available model and on the quality of the selected frames; the AI sees only the frames that were sent.
  • Short Clip sends a few sampled frames per clip, so an issue between two samples is placed at the nearest sampled frame.
  • Matching is manual — there is no automatic synchronization or scene detection.
  • Playback depends on the browser's codecs: H.264, VP8/VP9 and AV1 work; HEVC or ProRes .mov files often do not play in Chrome.
  • Each pair is one Codex task that can take seconds to minutes; there is no cancel button yet.
Get started

Run FrameMind AI on your computer

Extract one ZIP and double-click the Start file. The launcher checks what your computer is missing and asks before installing anything.

  1. Extract the ZIP

    Double-click FrameMind-Portable.zip. You can move the FrameMind-Portable folder anywhere — paths with spaces work.

  2. Double-click Start FrameMind.command

    A Terminal window opens and checks Python, FFmpeg and Codex CLI.

  3. Allow it the first time

    macOS may say the file cannot be opened, because the launcher is a script and not a signed app. You only do this once:

    macOS 15 and newer: click Done, then open System Settings → Privacy & Security and click Open Anyway.
    macOS 12–14: Control-click the file, choose Open, then click Open again.

  4. Install what is missing

    For each missing tool the launcher explains what it is and asks first in a small window: click Yes. The first launch needs internet and takes a few minutes; later launches start in seconds.

    HomebrewPython 3.9–3.13FFmpegCodex CLI (optional)

  5. Use the app

    Your browser opens FrameMind AI, already connected to the backend. Keep the Terminal window open while you work.

  6. Sign in for AI analysis

    Open Settings → AI Provider → Login with ChatGPT. Only needed once per computer.

  7. Optional: connect your Unity project

    Right above Analyze, choose Unity project → Add a project…, pick the project folder, then click Folders and tick only the folders the AI may read. Details in feature F above.

  1. Extract the ZIP

    Right-click FrameMind-Portable.zip and choose Extract All…. Running it from inside the ZIP does not work.

  2. Double-click Start FrameMind.bat

    A console window opens and checks Python, FFmpeg and Codex CLI.

  3. Allow it the first time

    If Windows shows Windows protected your PC, click More info → Run anyway. You only do this once.

  4. Install what is missing

    Tools are installed with winget after you click Yes in the window that asks, and Codex CLI is downloaded as FrameMind's own, auto-updated copy. If a tool is still "not found" right after installing, close the window and start again.

    Python 3.12FFmpegCodex CLI (optional)

  5. Use the app

    Your browser opens FrameMind AI, already connected to the backend. Keep the black window open while you work.

  6. Sign in for AI analysis

    Open Settings → AI Provider → Login with ChatGPT. Only needed once per computer.

The Windows launcher has not been run on a real Windows PC yet. If something fails, the window shows the error and the log is in %LOCALAPPDATA%\FrameMind AI\logs.
